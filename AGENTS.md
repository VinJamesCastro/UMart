## Agent skills

### Issue tracker

Product plans, specs, and implementation tickets live as local Markdown files under `docs/planning/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels. See `docs/agents/triage-labels.md`.

### Domain docs

Use the single-context layout, with `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
