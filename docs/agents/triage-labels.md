# Triage labels

The engineering skills use five triage roles. For local issues, write the corresponding value in the issue's `Status:` line.

| Role | Status value | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | Waiting for more information from the reporter. |
| `ready-for-agent` | `ready-for-agent` | Ready for an agent to implement. |
| `ready-for-human` | `ready-for-human` | Requires human implementation. |
| `wontfix` | `wontfix` | Will not be actioned. |

When a skill mentions a triage role, use the value in this table.
