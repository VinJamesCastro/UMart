# 26: Handle support issues

Status: ready-for-agent
Blocked by: 05 Review keyword-held Listings, 23 Report Members and activity

## What to build

A signed-in Member asks the founder for help with a technical, account, marketplace, messaging, safety, or payment-related concern that the FAQ does not resolve.

## Acceptance criteria

- [ ] The support form accepts category, short summary, description, optional related Listing, Member, or Order Request or Transaction, and private evidence.
- [ ] Categories cover technical, account/profile, Listing, request or Transaction, messaging, safety, payment-related, and other issues.
- [ ] The Member can see Open, Under review, Resolved, or Closed status and appropriate updates; the founder/admin can review and change status in a protected view.
- [ ] Evidence and private deal details are inaccessible to unrelated Members. Payment concerns may trigger conduct review but UMart does not decide debts or issue refunds.
- [ ] Tests cover submission, status updates, and cross-account access denial.
