# 07: Browse Home and Explore

Status: ready-for-agent
Blocked by: 02 Guest Live Listing discovery

## What to build

A visitor browses a Home feed with visible shortcuts to all four categories and searches Live Listings in Explore. Categories without real Listings invite the first Member to post.

## Acceptance criteria

- [ ] Home displays Live Listings across categories, helps visitors discover new, popular, or active offers, and has visible Food & Drinks, Marketplace, Services, and Errands / Pasabuy shortcuts.
- [ ] A shortcut opens Explore with that category selected; search works across all categories or within the selected category.
- [ ] Listing details open from Home or Explore. Unavailable Live Listings show their state instead of disappearing.
- [ ] An empty category has a clear empty state and a sign-in or posting path, without invented sample Listings.
- [ ] A running-app test checks search and category navigation. The controls remain usable on a phone-sized viewport and by keyboard.
