# 24: Block another Member

Status: ready-for-agent
Blocked by: 09 Message from a Listing, 10 Submit a Marketplace Order Request, 13 Confirm and cancel Transactions, 22 Filter all four categories

## What to build

A Member blocks another Member to stop new direct contact and remove that person's offers from their signed-in discovery, while keeping an existing Confirmed Transaction actionable.

## Acceptance criteria

- [ ] Blocking stops new direct messages and Order Requests between the two accounts in both directions, including direct data calls.
- [ ] The blocked Member's Listings are hidden from the blocker's signed-in views; a guest can still see otherwise public Live Listings.
- [ ] A previously Confirmed Transaction remains visible to both participants with cancel and report actions, but no new direct contact.
- [ ] Tests cover both directions, signed-in and guest discovery, existing Transaction access, and a third unaffected Member.
